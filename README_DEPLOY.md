### 🚀 Вариант 1: Бесплатное размещение на GitHub Pages (0 ₽ / навсегда) — Рекомендуемый
1. Создайте бесплатный аккаунт на [github.com](https://github.com/) (если еще нет) и новый публичный репозиторий (например, `zakharov-dom`).
2. Загрузите туда **все файлы из этой папки `HOSTING_READY`** (прямо в корень репозитория).
3. В настройках репозитория: `Settings` → `Pages` → `Branch: main / root` → Нажмите `Save`.
4. В строке `Custom domain` укажите: `zakharov-dom.ru` и поставьте галочку `Enforce HTTPS`.
5. В панели регистратора Beget в разделе DNS направьте домен на GitHub:
   - Добавьте 4 записи типа `A` для `@` (основной домен):
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
6. Сайт готов и открывается по защищенному протоколу: **https://zakharov-dom.ru/**

### 🚀 Вариант 2: Размещение на классическом хостинге (Beget / Timeweb)
1. В панели управления хостинга Beget откройте «Файловый менеджер».
2. Перейдите в директорию вашего сайта (`public_html` или `zakharov-dom.ru/public_html`).
3. Загрузите туда **все файлы из папки `HOSTING_READY`**.
4. В панели Beget в разделе «SSL-сертификаты» включите бесплатный сертификат Let's Encrypt в один клик.
